# Web Payment QRIS

Website payment static modern untuk 2 QRIS:

- TOKO TMHR, MATERIAL BANGUNAN
- Zabu Cloud

Fitur:

- Responsive desktop dan mobile
- Pilihan QRIS pakai button
- Download foto QRIS
- Copy nomor DANA/GOPAY
- Copy detail pembayaran
- Animasi modern ringan

## Cara pakai lokal

Buka file `index.html` di browser.

## Cara deploy Netlify

1. Login Netlify
2. Drag & drop folder ini ke halaman Deploy
3. Tunggu proses selesai
4. Link website siap dipakai

## Cara deploy Vercel

1. Upload folder ini ke GitHub
2. Import repository di Vercel
3. Framework pilih `Other`
4. Deploy
